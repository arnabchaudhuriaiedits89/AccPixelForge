# AccPixelForge

AI Creative Studio web application built with Gradio and backed by RunPod Serverless inference.

## Features
- Text-to-Image generation with aspect ratio presets and AI upscaler selection
- Quick AI Retouch with multi-reference slots and slash command prompts (`textprompts_config.py`)
- Dynamic Flow AI & Master Prompts library (`prompts_config.py`)
- Multi-Asset Storyboard & 3D CGI Billboard studio
- Cinematic Video, Image-to-Image, Image-to-Animation, Face Swap, Background Eraser, Preset Gallery (`preset_prompts_config.py`), Prompt Enhancer, and Assistant Chatbot

## Environment Variables
- `RUNPOD_ENDPOINT`
- `RUNPOD_API_KEY`
- `PORT` (optional; defaults to `7860`)
